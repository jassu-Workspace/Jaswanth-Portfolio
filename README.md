## 🛠️ Deploying This Portfolio

This exact portfolio is built natively with **Next.js 16**, **React 19**, **GSAP** & **TailwindCSS**, utilizing advanced Framer Motion transitions and Three.js canvases.

```bash
# 1. Clone the repository
git clone https://github.com/jassu-Workspace/Jaswanth-Portfolio.git

# 2. Enter the directory
cd Jaswanth-Portfolio

# 3. Install the dependencies
npm install

# 4. Start the development server
npm run dev
```
